# Changelog

## 2.0.0 (2026-10-20)

双模式架构版本。

### 新增
- 🔒 隐私模式：本机网页工具（127.0.0.1），图片全程不经过 AI 对话与外部服务器，零落盘零记录
  - 虚线框两用：点击弹系统原生文件框（直接获取原图真实路径）；拖入自动反查原图位置
  - 拖入即定位：图片进入列表立即后台反查，实时显示「已找到原图 / 同名原图 / 未找到原图」
  - 两级匹配：同名+同字节大小精确匹配优先；仅同名时名称兜底（图片特征目录优先，命中后自动收窄搜索窗口）
  - 自动写回原图所在文件夹，`-compressed` 后缀命名，不覆盖原图
  - 反查不到原图（截图未另存）时自动压缩副本，首次使用提供一次性「选择保存位置」
- ⚡ Agent 模式：指定大小（KB/MB）和/或尺寸，自动定位原图、压缩并写回
- 字节级精确限额：平台十进制限额自动留 5% 余量
- 二分搜索最大化 JPEG 质量；质量不足时自动降分辨率换画质；透明图自动 PNG 调色板

### 技术说明
- 本地服务仅监听 127.0.0.1，无任何外部网络请求
- 无日志、无配置文件、无持久化存储；临时文件用完即删
