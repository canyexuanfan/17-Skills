# 本机隐私图片压缩 (Private Local Image Compress)

> v2.0.0 · 2026-10-20 · 图片全程留在本机压缩，AI 不看你的图，零上传零记录，结果自动写回原图所在文件夹。

## 为什么需要它

把图片发给 AI 处理的那一刻，图片就离开了你的电脑：进入对话上下文、产生平台缓存副本。对于证件照、合同/发票截图、私人照片、商业敏感素材，这往往不可接受。

本技能提供**隐私模式**：一个运行在你自己电脑上的网页工具（127.0.0.1 本地服务），图片从磁盘到浏览器到本地服务，全程不经过任何 AI 模型、不上传任何外部服务器、不产生任何记录（无日志、无配置文件、临时文件用完即删）。

## 两种模式

| | 🔒 隐私模式 | ⚡ Agent 模式 |
|---|---|---|
| 谁操作 | 你在网页里自己拖图/点选 | 直接对 AI 说要求 |
| 图片去向 | 仅本机（浏览器 ↔ 本地服务） | 进入 AI 对话上下文 |
| 记录 | 零（服务退出即消失） | 对话记录中包含图片 |
| 适合 | 证件照、合同票据、私人照片、商业图 | 日常普通图片，图省事 |

## 能力边界（各管一段）

| 能扛住 | 扛不住 |
|---|---|
| JPEG/PNG 压缩到指定字节大小（十进制限额自动留余量） | GIF 动图、WebP 动图 |
| 保持原尺寸 / 限制最长边 / 指定宽高 | 内容感知裁剪、美化、抠图 |
| 透明图自动走 PNG 调色板 | CMYK 专业印刷色彩管理 |
| 自动写回原图所在文件夹（不覆盖原图） | 跨设备同步、云端备份 |
| 拖入自动反查原图位置（同名+同大小精确，同名兜底） | 从未保存过磁盘的纯剪贴板图片（会按副本压缩并明确提示） |

## 实测数据

| 场景 | 结果 |
|---|---|
| 拖入图片，冷启动全盘反查原图（G 盘，含大目录） | 0.31~1.1 秒命中 |
| 点击选择（原生文件框直接拿路径） | 即时 |
| 1254px 插画压至 95,000 字节（100KB 平台限额） | 93,782 字节，质量 65，自动降分辨率至 977px |
| 1254px 原图压至 512×512 + 500KB 限额 | 100,281 字节，质量 95 |
| 名称兜底匹配（大小不同的同名原图） | 约 11 秒定位 |
| 反查不到原图（截图未另存） | 自动压缩副本并明确提示 |

## 隐私承诺

- 本地服务仅监听 `127.0.0.1`，无任何外部网络请求，代码可审计。
- 无日志、无配置文件、无浏览历史；临时文件用完即删。
- 唯一的"记忆"是进程内存中本会话成功保存过的文件夹路径，服务退出即消失。
- 本包不含任何真实用户数据。

## 快速开始

**隐私模式（Windows）**：双击 `scripts/start_privacy.bat` → 浏览器自动打开 → 拖入图片或点击虚线框选择 → 设置参数 → 开始压缩。macOS/Linux：`python scripts/privacy_server.py`。

**Agent 模式**：安装本技能后直接对 AI 说「把这张图压到 100KB 以内」「改成 512×512 并压到 500KB」，AI 会自动完成并写回原图文件夹。
