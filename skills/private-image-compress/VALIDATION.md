# 实测校验记录 (VALIDATION)

所有数据为 2026-10-20 于 Windows 11 + Python 3.13 + Pillow 12.3 环境实测。

## 压缩质量

| 测试 | 约束 | 结果 | 结论 |
|---|---|---|---|
| 1254×1254 插画 → 100KB 平台限额 | ≤95,000 字节（含余量） | 93,782 字节，977×977，q65 | 通过，自动降分辨率保画质 |
| 同图仅尺寸 512×512 + 500KB | ≤475,000 字节 | 100,281 字节，q95 | 通过 |
| 同图仅尺寸 800×800 长边 | 无大小限制 | 800×800，q92 | 通过 |
| 512×512 + 50,000 字节 | ≤50,000 字节 | 49,636 字节，q80 | 通过 |
| 不可能约束（100 字节） | ≤100 字节 | 报错提示放宽约束 | 通过（错误处理） |
| 透明 PNG | 自动格式选择 | PNG 调色板路径 | 通过 |

## 原图定位（隐私模式拖入场景）

| 测试 | 结果 |
|---|---|
| 冷启动全盘反查（同名+同大小，目标在 G 盘 3 层深） | 0.31~1.1 秒命中 |
| 点击选择（原生文件框） | 即时获得完整路径 |
| 名称兜底（同名但大小不同的原图） | 约 11 秒定位 |
| 磁盘无原图（截图未另存） | 正确进入副本压缩分支并提示 |
| 不存在的文件名 | 正确返回未找到 |

## 隐私验证

| 检查项 | 结果 |
|---|---|
| 服务监听地址 | 仅 127.0.0.1:8765 |
| 外部网络请求 | 无（代码审计 + 行为观察） |
| 运行目录残留文件 | 仅 3 个源文件，无日志/配置/临时文件 |
| 临时文件 | 压缩用 tempfile，finally 中删除 |
| 会话缓存 | 仅进程内存，服务退出即消失 |

## 已知边界

- GIF/WebP 动图不支持（会按静态首帧处理或报错）
- 名称兜底匹配在极端情况下（同名文件散布多处）可能命中非目标副本，结果区有「同名原图，大小不同」标注
- Windows 专用一键启动 bat；macOS/Linux 需手动运行 `python scripts/privacy_server.py`
