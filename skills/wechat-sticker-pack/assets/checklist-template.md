# 投稿前自查清单

## 硬性项（❌ 不过就不能投）

- [ ] 表情图数量 8~24 张（任意数量，非固定档位）
- [ ] 全套统一：全部动态或全部静态，不混用
- [ ] 表情主图 240×240：动态 GIF / 静态 PNG、JPG、GIF，单张 ≤500KB
- [ ] 封面图 PNG 240×240 ≤500KB
- [ ] 聊天面板图标 PNG 50×50 ≤100KB
- [ ] 详情页横幅 PNG/JPG 750×400 ≤500KB
- [ ] （可选）赞赏引导图 750×560 ≤500KB、致谢图 750×750 ≤500KB

## 建议项（官方"应/避免"措辞，实测不卡，但达标更稳）

- [ ] 封面/图标透明背景（官方写"须"，但实测不透明也上架过）
- [ ] 封面/图标无白色描边、无锯齿、无正方形边框
- [ ] 横幅无文字信息、非透明底、避免白色背景
- [ ] 动态表情循环播放、节奏流畅
- [ ] 各表情含义不重复、风格统一、差异足够

## 文案规范

- [ ] 表情名称 ≤8 汉字（≤5 显示最佳）、无标点、无空格、不与已有专辑重名
- [ ] 表情介绍 ≤80 汉字
- [ ] 含义词 ≤4 汉字、同套不重复、普通话、避免标点
- [ ] 版权信息 ≤10 汉字
- [ ] 赞赏引导语 5~15 汉字（如要开赞赏）

## 投稿

- [ ] sticker.weixin.qq.com 注册（个人/企业，中国大陆身份实名）
- [ ] 提交后审核 ≤5 个工作日；关注"微信表情开放平台"公众号收进度
- [ ] 被驳回可修改重投；上架后每自然月限修改一次
- [ ] 赞赏需上架后主动申请，且投稿时已传引导图/致谢图
