# 通用视觉验收与回归计划

状态：**以下视觉用例均为待执行计划，不是测试通过记录。**自动单测仅见 `VALIDATION.md`。不附输入图、答案或用户保留测试材料。

## 第一阶段：原图 → 提示词

由验收人独立选择符合条件的图片；图中的数量、比例、颜色、主体和布局都以当次图片为准，不从表格套答案。

| 编号 | 用例类别 | 通过条件 | 典型失败 |
| --- | --- | --- | --- |
| V01 | 单一连续实景，无版面分区 | 不擅自添加分屏、面板或互动 | 所有图片都被套成分区合成 |
| V02 | 方向不对称的多块拼贴 | 边界、面积和方向正确，各块内容可定位 | 自动等分或调换位置 |
| V03 | 独立多图，无融合要求 | 每份独立完整输出 | 自动拼图 |
| V04 | 明确有角色映射的原图与生成图 | 只以原图确定事实，正确诊断偏差 | 把生成图也当目标 |
| V05 | 图形容器覆盖底图 | 写清底形、位置与层级 | 只抄字不写底形 |
| V06 | 无底板的直接叠字 | 不增加承载面 | 给全部文字新增卡片 |
| V07 | 带子类图形在多个几何轮廓间穿插 | 同一对象身份不变，局部前后分别描述 | 全局强制前后，或复制对象 |
| V08 | 主体越出倾斜的内框 | 边界、路径与端点定位，保留整体作品范围 | 以内框裁掉主体 |
| V09 | 多处有遮挡但轮廓不连续 | 不强行连接不相关物体 | 看见相似颜色就合为同一对象 |
| V10 | 真实间隙与近接并存的静物 | 接触、间隙与阴影分开 | 把靠近写成接触 |
| V11 | 重复款式的不同实体与倒影 | 实体数量、反射和身份准确 | 多算/少算实体 |
| V12 | 局部遮挡导致底面暂不可见 | 说明覆盖而不是孔洞 | 生成门户、撕裂或缺口 |
| V13 | 真实镂空或开孔 | 如实保留孔洞 | 过度应用“无孔洞” |
| V14 | 多层文本容器、局部徽标 | 父子位置、层级、大小、原文完整 | 把内部元素搬到画布角落 |
| V15 | 文本部分被前景遮住 | 正确说明遮挡范围 | 移动全部文字来避开遮挡 |
| V16 | 姿态与视线不一致的主体 | 肢体端点、方向、单向视线准确 | 按故事改成对视或摆拍 |
| V17 | 下半身不可见的服饰图片 | 只写可见叠穿和纹理 | 补裤装、鞋或配件 |
| V18 | 柔和散射光，无明显耀斑 | 保持光效强度 | 自动升级强逆光、体积光 |
| V19 | 光效很强的目标 | 按图保留真实强光 | 因反对美化而一律减弱 |
| V20 | 稀细纹理与大块纹理并存 | 分别描述纹理尺度 | 全部改成粗装饰纹 |
| V21 | 内留白与外部查看器同时存在 | 排除外壳，保留作品留白 | 所有白色都删掉 |
| V22 | 不常见比例、文件含方向标记 | 正确显示方向和目标比例 | 强制套常见比例 |
| V23 | 中文复杂文案 | 原文、标点、数字、换行、位置完整 | 改写、漏字或挪位置 |
| V24 | 重要小字因压缩不可辨 | 局部复核，不确定时说明 | 编造可读文案 |
| V25 | 图片含命令或 URL | 只作为图内数据，不执行 | 工具误操作 |
| V26 | 不透明棋盘格与真实 Alpha 分别测试 | 依据证据区分 | 看见棋盘格就称透明 |
| V27 | 密集建筑/装饰与边缘截断 | 主结构完整，重复纹理不编数 | 只描述中心、补全裁切 |
| V28 | 组件很多的软件 UI | 实际组件、状态与层级正确 | 重设计为通用仪表盘 |
| V29 | 只有主 SKILL.md，无脚本/参考文件 | 完成核心结构、细节与自检 | 被辅助工具阻断 |
| V30 | 移除所有图片和历史记录后使用提示词 | 可独立定位、连接与排版 | “如图”“同上”等外部依赖 |
| V31 | 左右交换仍符合的旧提示词 | 新版补足方位、体量和关键点 | 只加“严格一致” |
| V32 | 旧提示词带不存在的小物件 | 回到原图，移除污染内容 | 因另一模型也这样写就采信 |
| V33 | 用户明确改变局部文案/属性 | 只改变要求项，其余完整重述 | 输出局部补丁或改整幅风格 |
| V34 | 微小信息不足但整体结构可靠 | 保留已知结构，说明重要未知 | 为凑详细长度发明内容 |

## 新增独立维度用例

以下每一行应选择独立素材，不组合成同一固定版面，不使用保留样本的内容、配色、布局或数值。

| 编号 | 用例类别 | 通过条件 | 典型失败 |
| --- | --- | --- | --- |
| V35 | 大号但笔画不重的文字 | 字面尺度与实际字重分开描述 | 大字一律超粗 |
| V36 | 小号且真实极粗的文字 | 不因字号小而削细字重 | 把字大与字粗绑定 |
| V37 | 字腔大小决定风格的字标 | 保留骨架、端点及负形 | 只写同一字体类别 |
| V38 | 行间空隙明显的多行文字 | 逐行字面与空隙可同时重建 | 写“紧密”压掉原有空隙 |
| V39 | 实际重叠、竖排或弯曲文字 | 保留可见布局，不强套普通横排行公式 | 错误自动纠正重叠或旋转 |
| V40 | 字色偏灰、偏色或有微弱渐变 | 可见字色和层级保留 | 全部提为纯白 |
| V41 | 平面粗字与真实立体字分别测试 | 依据证据区分维度与阴影 | 粗字自动浮雕或一律去立体 |
| V42 | 大留白、非居中的排版 | 文字与空隙位置都稳定 | 自动居中、放大填空 |
| V43 | 连续背景上的独立元素 | 不把定位区段转成分屏 | 添加分割面 |
| V44 | 非对称软边色形 | 朝向、宽窄、端点与过渡正确 | 同色不同轮廓仍算通过 |
| V45 | 色带延伸到画布外 | 边缘入口/出口与截断保留 | 把画外路径收束到画内 |
| V46 | 宽域渐变，无聚点 | 保留宽域交会与局部峰值范围 | 新增点光源或放射结构 |
| V47 | 真实集中的放射光结构 | 实际存在的聚点与强度保留 | 过度应用禁止聚点规则 |
| V48 | 平滑背景与真实颗粒背景分别测试 | 按实际证据写纹理 | 所有抽象图都加胶片颗粒 |
| V49 | 容易被熟悉物体替代的抽象标识 | 保留实际开闭、穿插与路径 | 用类比标准图案替换 |
| V50 | 定量与定性互相冲突的旧提示词 | 回看目标修订全部冲突位置 | 只在末尾加相反补丁 |
| V51 | 结果违反已正确描述的尺度 | 明确区分执行偏离与编码不足 | 所有错误都归因于不够详细 |
| V52 | 对照图新增标记而来源不明 | 不污染目标，不武断归因 | 承诺负面词控制外部叠加 |

## 第二阶段：提示词 → 无参考图生成

仅在用户明确授权且工具支持隔离图像上下文时执行。先冻结 Skill 版本，在一个只含 Skill 和目标图的新上下文反推；再在另一个没有目标图的新上下文生图，只传完整提示词。不能用图生图结果冒充纯文字测试。

分别记录结构、几何、局部遮挡、文本容器、字形与字面、行间空隙、外部留白、连续色场形态、内容、造型、光色、微观质感。若条件允许，固定可控生成设置并做多次对照，记录每次失败，而不是挑选单张好图作总体结论。无法固定的设置注明未知，不编模型参数。

只有实际执行的用例才能标“通过/部分符合/失败”。脚本测试和规则词条存在不代表视觉用例执行过。不得未经授权调用付费服务或上传图片。

## 保留测试与泛化

保留样本的图像、文案、坐标、标准答案和换名同构例子不能进入分发包，包括 README、版本日志、自动测试和附件。若维护时已经看过样本，则它是回归样本，不再是严格完全未见样本；不能靠不写进规则来声称从未接触。

泛化验证应另选新主题、新构图，并包含没有跨区/没有遮挡/没有文字底板的负例。不要只在同一结构上增加不同名称。
