# 连续色场、软边轮廓与抽象结构协议

适用于连续渐变、模糊色块、光带、抽象图形和颜色承担主构图的作品。也可用于照片中的主导光色区域，但不能因此把真实物件误写成抽象背景。这里不规定配色、方向、色区数量或模板布局。

## 1. 先分类视觉事实，不猜制作方式

区分连续色场、独立图形、真实光照、实体表面和混合效果。称为色场仅说明颜色在画面中连续变化，不证明采用网格渐变、某种滤镜、矢量路径、摄影长曝光或特定软件。

为观察方便划分的位置区段不是物理分屏，不得生成新分割线。软边颜色有结构，但未必存在独立图层。没有硬边不等于没有方向、轮廓、体量与边界带。

先写可见的形态，再选择可用的风格词。会诱发额外星点、雾、光源、射线、镜面、门户或具象场景的类比，在没有证据时不要使用。

## 2. 三种观察尺度

**整体尺度**：低频亮暗分布、最大色形、面积、重心、颜色连通性、正负空间与主要方向。对象很少时，这些仍可能需要较多描述。

**形状尺度**：主要色形的包络、两侧边缘、宽窄变化、弯曲、端点、渐变带宽、局部交叠和边界进出画布位置。

**微观尺度**：颗粒、平滑、条带、压缩、微纹理与锐度。先确保整体和形状正确，再处理细小噪点。不可见颗粒不因常见风格而自动添加。

必要时缩略查看大色块，再放大边缘；如实际使用模糊/降采样预览，记录其只是辅助图，不能据此抹掉原本可见的小结构或冒称做过生成验证。

## 3. 每个主导色形的事实字段

| 字段 | 必须回答的问题 |
| --- | --- |
| 可见范围 | 在目标哪里，占多大，是内闭形还是触及/越出画布？ |
| 主轴或路径 | 沿什么方向延伸、转弯，有没有明确端点？ |
| 两侧轮廓 | 边缘分别怎么走，是否平行、弯曲、折转、不对称？ |
| 宽窄变化 | 哪一端宽、哪一端窄，沿路径怎样变化，是否真的收束？ |
| 过渡带 | 锐利、半软或很软，边缘渐变多宽，有没有内部亮芯？ |
| 颜色路径 | 沿主轴及横跨主轴的颜色、明暗和饱和度怎样变化？ |
| 相邻关系 | 接着什么色形，是融合、覆盖、并列还是有间隙？ |
| 亮暗峰值 | 是大范围明亮/阴暗、沿边亮带、小斑还是实际聚点？ |
| 画布边缘 | 从哪段边界进入、沿边延伸或退出，是否被画框截断？ |

字段只作用于影响构图的主要形状，不强迫逐色逐像素描写。模糊边界用“约在……范围逐渐过渡”，不能假装有精确分割线。选择少量稳定锚点，位置说明应可被自然语言执行。

## 4. 正空间与暗色/负空间同等重要

大面积暗区、空区或近单色区可以像实体主体一样决定构图。记录它的包络、宽窄、开口、尖角或圆钝端以及与周围亮区的关系。不要只列亮色，而把暗区写成无形的“黑底”。

“斜向形状”不足以限定宽窄方向。核对主轴、宽端、窄端和转折；不能把不同朝向的非对称形状描述成同一种楔、扇或带。看不到尖端就不推测尖端在画面内。

面积占比是最终可见范围的估计，半透明融合区可以重叠；不要求所有色名的占比严格加到整幅。不能拿全图色板份额当成某区域的精确面积。

## 5. 交会、收束和发光必须分开

多色接近不等于接触，多条渐变交会不等于同一个点，最亮处不一定是发光源。分别判断：

- 过渡是否覆盖较大区域，还是确实有小范围峰值？
- 是带与带交叠、形状交界，还是射线从单点发出？
- 端部是否收束在可见点，还是延续到画外？
- 是亮芯、模糊外缘、角部混色，还是有可见星芒和放射方向？

没有相应证据不能使用“从一点射出、聚焦、相交于一点、发光尖端、放射中心”来讲故事。若实际存在集中点或光束，则应写清其位置、大小、方向与强度，不能因本协议而删掉。

暗形不一定是真实阴影；抽象色带不一定是物理光束。光学类词汇应反映形态，而不是引入模型自行补齐的发射器、透镜或空间。

## 6. 颜色按局部外观分配

区分色相、明度、饱和度和对比。峰值色很鲜明不代表整个大色区高饱和；暗色范围很大不代表所有角落全黑；明亮也不等于接近白色。写清弱色区、过渡色和峰值所在范围。

色带沿长度的变色和横跨边缘的过渡可能不同，要分别写；渐变的方向不能只靠几个色名的排列让模型猜测。不要仅凭“冷暖对比”忽略具体轮廓与面积。

色彩取样可辅助核对，但普通合成栅格不能唯一恢复原始渐变控制点、Alpha、混合模式、ICC 后的显示外观或源图层参数。给采样色时标明近似；默认用可见颜色和位置即可。

## 7. 边缘、柔焦与纹理互不替代

软边仍可能有相对明确的形状包络。把过渡描述得过宽会改变轮廓，过窄会变成硬几何切块；判断过渡宽度相对于色带、附近文字或画布的量级，不武断指定未知滤镜半径。

平滑渐变、真实失焦、浓雾、晕光、胶片颗粒、抖动噪点、色阶断带和压缩痕迹分别描述。只有整幅的稳定证据支持时才加“均匀颗粒”等全局性质。

## 8. 软边结构反事实检查

保持色名不变但交换亮暗面积、反转宽窄端、改变对角线、移动边界入口/出口、把宽域过渡变成单点放射、把连续背景切成独立色块，是否仍符合提示词？

如果是，缺少的是形态与连接信息，不是更多色彩形容词。修订对应正向结构句，并仅加入本图相关排除项。没有实际生成对照图时，不称为已通过复刻测试。
