# 约束一致性与描述基准

目的：避免提示词每段单独看都合理，组合起来却要求不同的画面。此文件不要求用户填表；检查由执行 Skill 的 Agent 完成。脚本无法代替语义复核。

## 1. 建立单一描述基准

从原图建立简明可见事实记录：属性、证据、位置或范围、可信度、影响程度。只保存任务所需的观察记录，不输出私有推理过程。主描述与最后重申从这同一记录派生，不能各自猜数。

同一属性不同时拥有多套不一致约束。修改一个位置时，同步检查中心、尺寸、边距、邻接、文字所属区域与末尾约束。不能只在末尾增加“以此为准”而保留早先相反的句子。

## 2. 事实与形容词一致

| 容易冲突的组合 | 应核对什么 |
| --- | --- |
| 区域边界与“居中/偏上/占满” | 是上沿还是中心，实际范围与空隙是否相容 |
| 字面大小与“超粗/巨大/紧密” | 字号、字重、字距、行间字面空隙是否被混同 |
| 文本总宽与字宽、字距 | 是否要求压扁字形或制造额外间隙才可实现 |
| 整体组高与逐行高度、空隙 | 在普通横排条件下尺寸能否闭合 |
| 纯白/高饱和与局部浅色/弱色 | 全局词是否抹掉局部外观差异 |
| 无硬边与明确软边轮廓 | 软化是否被错误理解为没有形状 |
| 连续渐变与固定分屏 | 观察位置区段是否被误当成独立底图 |
| 同一对象与逐区新建对象 | 身份与数量是否在重复描述时发生变化 |
| 形状相邻与聚点/光源词汇 | 叙述有没有引入原图没有的物理因果 |
| 平面字与厚重/浮雕式形容 | 是否无依据引入描边、影子或挤出 |
| 具体路径结构与熟悉图标类比 | 类比是否替换了可见曲线连接方式 |

数字和形容词冲突时回图修正，不简单认为数字一定正确。范围不能无限放宽来容纳所有矛盾；关键锚点使用足够收敛、可由证据支持的近似。

## 3. 避免重复改写造成的漂移

开头只概括真实高影响结构；细节段给完整参数和关系；结尾只保留少量确实易错的约束。不在结尾给新坐标、新字重、新物件或新光效。

同义词不一定同义于视觉结果。暗色不自动是阴影，柔和不自动是浓雾，亮色不自动是发光，粗字不自动是立体，斜向不自动是楔形。删去不必要的因果和主题联想。

同样的详细程度应来自更多可核验的视觉事实，不是增加重复强调或相互竞争的风格标签。背景很复杂时多写边界路径；文本很重要时多写字面形态；实物很重要时多写结构与接触，不平均凑字数。

## 4. 约束作用范围

每条规则说明作用于全图、某个区域、某个文字组或某个对象。全图“无几何图形”等笼统禁令不能误伤真实标识或色形；“无文字”不能与转录文案并存。

禁止新增的内容与原图已有内容分开。用户明确修改优先；无修改要求时不擅自清除原有署名、压缩特征或裁切。不复制生成结果中新出现的水印或标记回目标。

## 5. 严重度与修复

优先修复会改变构图、身份、字形或主要色形的错误；再修次要纹理。文字再准确也不能抵消排版上移，颜色再相近也不能抵消轮廓方向颠倒。

检查状态可为“已写清、缺失、不适用、无法确认”。规则存在不等于已执行；总分不得掩盖高影响缺失。无法确认的重要项在输出外说明，不假装完整。

## 6. 提示词问题与执行问题分开

如果提示词已明确正确规定，而结果仍违反，则是该次的执行偏离记录；可减少竞争指令、前置高影响要求，但不能承诺改措辞一定解决。实际尺寸、模型设置、上下文继承、后叠加水印等属于独立核查项。

一次结果不能判定唯一因果。没有实际重复测试，不宣称哪项修改提高了多少相似度。不把无参考图上下文和普通图生图混为一谈。
