# 原图、提示词与生成结果的对照协议

## 1. 明确资料角色

先识别用户指定的目标原图、待诊断提示词、对应生成结果、明确修改要求及其他参考。用户已经说明映射时直接使用；真正无法确认时才澄清。对照任务不能套用“多张图片各输出一份”的默认规则。

原图是可见事实来源。提示词是待检查的描述，不是证据；生成图是待比较的结果，也不是新的标准图。多份提示词互相印证仍不能替代原图。某份提示词更流畅或某张生成图更漂亮，不代表更忠实。

## 2. 同一尺度比较

分别读取每张图片的尺寸与方向；以各自整幅作品归一化坐标进行比较。不因为显示宽度不同就判断主体大小改变，也不能为比较而先随意裁切、拉伸或改变比例。

按以下顺序记录目标、提示词规定、生成实际呈现和不确定项：

| 顺序 | 对照项目 |
| --- | --- |
| 结构 | 区域数、边界、方向、底形、留白、嵌套和覆盖 |
| 几何 | 主体中心/范围/体量、交互节点、边界比例、透视 |
| 关系 | 跨区连续、对象身份、局部遮挡、接触、视线 |
| 文字 | 原文、父容器、子组件、全局位置、内部对齐 |
| 排版 | 整体与逐行字面框、字形骨架、笔画/字腔、行间空隙、字距、边距、可见字色 |
| 标识 | 可见曲线路径、开闭、穿插、线宽、负空间、与字标比例 |
| 连续背景 | 亮暗包络、面积、方向、宽窄、边缘入口/出口、交会形态、渐变过渡带 |
| 内容 | 可辨数量、造型、服饰层次、道具、边缘裁切 |
| 表现 | 媒介、色彩、光影强弱、纹理尺度与成像 |

不得用“主题一样、物件相似”代替结构对照。不得以“信息都在”掩盖“位置不对”，以“文案相同”掩盖“字面变大/笔画变粗/留白改变”，或以“色名一样”掩盖“色形方向与面积不同”。

位置与尺寸注明量的是字面上沿、中心还是整体框；行间空隙单独计算。可在人工确认的区域做只读像素统计辅助，但阈值会受到背景和抗锯齿干扰，不称为自动识字或精确版面解析。观察近似不要给虚假的精密百分数。

诊断每个高影响差异时，保持“原图可见事实—旧提示词的具体规定—生成实际表现—原因与置信度”这一对应关系。不从结果反推它必然由某个词导致。

## 3. 将偏差定位到合适环节

- **观察错误**：描述与原图直接冲突，或旧提示词把并不存在的东西写成事实。回看原图后删除/改正。
- **编码不足**：提示词没有规定区域、位置、关系或组件归属，多个不同构图都符合文字。补充自然语言几何和关系。
- **内部矛盾**：前后段落规定互斥的布局、数量、遮挡或比例。修改所有冲突位置，不能只在最后加补丁。
- **执行偏离**：提示词已明确规定，而该张生成结果未遵循。保留这一事实，必要时简化冲突密度并强化重要约束，但不能保证一定消除偏差。
- **外部设置/能力限制**：实际输出比例、裁切、透明度或上下文与目标不符。独立记录，不静默修改目标来迎合结果。
- **原因未确定**：没有完整生成设置或足够复测时，只记录观察，不把相关性说成唯一原因。

同一偏差可以同时有多个原因。不能从一组样本推出不同模型能力的全面排名，不能编相似度。

排查文本冲突时特别核对：数字边界与“大/紧/粗”等词，行高/空隙与整体组框，连续色场与分区措辞，具体标识路径与类比，局部浅色与全局纯白/高饱和，画内色区交会与物理发光源词汇。

提示词已经明确规定而结果仍偏离时，要保留“执行偏离”结论，不能把所有问题改写成“原来没写详细”。新增角标/署名/水印可能是生成内容，也可能由外部流程叠加；没有证据时不确定来源，不向用户承诺提示词能控制后者。

## 4. 输出修订与维护不同

用户要修订提示词：交付完整的新提示词，仍以原图事实为依据。只有用户要求分析，才附相应差异说明。不要擅自交付图生图参数或直接出图。

用户要维护 Skill：改进通用工作流、强制检查点和表达规则，交付文件；不把案例的标准答案塞进包里。特别是用户保留作后续测试的材料，不得存入任何交付目录，也不得用改名后的相同布局充当“通用示例”。

## 5. 验收隔离

维护规则从失败中提炼，但不能声称接触过的样本仍是统计意义上的完全未见测试。未写入包只说明没有把答案随 Skill 分发，不等于开发过程从未看过该样本。

回归测试可以使用原样本；检验泛化还应使用不同主题、不同布局和没有同类结构的负例。新的反推测试放在不含旧提示词、生成结果和本轮分析的新会话，仅提供 Skill 与目标图。后续纯文字生图再用另一个不含参考图的上下文，只提供完整提示词。

维护者不能声称已经替用户隔离了某个平台的上下文，除非实际工具操作可确认。工具自动继承图像、模型/种子/尺寸变化等，均应单独记录。
