# 交付前质量门

检查结果用于修订，不用于编造相似度。重要事实不可确认时应说明缺失，不得把未知记作通过。

## A. 一票退回

存在以下任一问题，必须先修订完整提示词：

1. 未真实查看目标图，却写出具体画面；将生成结果或旧提示词当作原图事实。
2. 将场景数直接当作版面区域数，漏掉大型信息面、留白、框架或底形。
3. 把有越界/覆盖的构图写成互不相关的独立分屏，或者凭空添加跨区结构。
4. 只说“互动/破框”而未说明关键路径、边界、位置、局部遮挡及终点。
5. 给整个对象套错误的全局层序，切断连续部分，重复共享物体，或把遮挡误画成孔洞。
6. 文案存在但承载它的形状/位置消失，文本组件可以任意迁移或重组。
7. 关键主体中心、相对方向、体量或交互位置缺失，左右互换仍能满足文字。
8. 用截图外壳尺寸代替目标比例，或把非标准比例无说明改为标准比例。
9. 修改了可辨数量、服饰结构、视线、纹理尺度、主要配色、光线强度或裁切。
10. 虚构不可辨文字、道具、精确年龄、身份、品牌型号、摄影参数或源图层信息。
11. 正面描述、结构摘要、细节或排除项彼此矛盾；依靠末尾一句否定前面整套错误描述。
12. 提示词含外部依赖、未填占位符，或者需要用户手工拼接才能生成。
13. 声称已验证必然一致、像素级复刻或相似度，而没有相应实测证据。
14. 重要文字只转录文案，而不锁定可见字面、字形、笔画/字腔、行间空隙、外部留白与字色。
15. 用“紧密、超粗、占满”等词与已给边界和空隙互相冲突，或混淆上沿、中心、字面高度和字号。
16. 连续背景只列色名，缺失重要亮暗轮廓、宽窄、过渡带、边界出入口，或把观察区段变成分屏。
17. 将宽域渐变、色带交叠或边缘亮区无证据改成汇聚点、物理光源、真实阴影或放射结构。
18. 用熟悉物体或常见图标类比替代标识的真实闭合、交叉、路径和负空间。
19. 将局部浅色统一成纯白，将少量亮色放大全图高饱和，或无证据添加颗粒、立体字和强化光效。

## B. 分项证据检查

逐项标记“已写清 / 缺失 / 不适用 / 无法确认”，不以总分掩盖任何结构缺失。

| 检查域 | 必查项目 |
| --- | --- |
| 输入 | 原图和对照图的角色、目标边界、用户明确修改 |
| 画布 | 方向、比例依据、作品尺寸与容器尺寸、内外留白和透明状态 |
| 版式 | 区域与场景的区别、边界形状/位置、尺度、嵌套、留缝、覆盖 |
| 几何 | 主体范围/中心/体量、相对方向、动作节点、主要透视和负空间 |
| 连续性 | 同一对象的身份、越界点、可见路径、遮挡后再现、终点 |
| 局部遮挡 | 谁在前、遮到哪一部分、底面是否延续、是否误加孔洞 |
| 动作 | 关键部位、接触对象、间隙、支撑、共享物体数量、视线目标 |
| 图文组件 | 父容器全局位置与底形、子标签、文字原文、局部对齐、遮挡 |
| 字面与留白 | 逐行可见框、整体框、字间/行间空隙、与画布/其他元素间距、坐标含义、几何闭合 |
| 字形与标识 | 骨架、字腔、笔画粗细、端点、宽高、字色；标识路径/开闭/穿插/负空间 |
| 连续背景 | 主要亮暗包络、色区面积、路径、宽窄变化、拐点、过渡带宽、边缘出入口、交会与聚点的区别 |
| 描述基准 | 同一属性前后一致、定性定量一致、作用范围明确、无暗含的物理因果 |
| 内容 | 主体、环境、四角、被裁切物、密集重复物与细节数量 |
| 造型 | 服装层次、形状、纹理尺度、可见身体部分、关键饰品 |
| 风格 | 媒介、描边、笔触、渲染、写实程度与原有不规则性 |
| 光色 | 方向、软硬、强度、对比、渐变、局部配色，是否夸大特效 |
| 成像 | 景深、焦点、噪点、锐度、压缩、眩光与原图证据 |
| 独立性 | 没有原图仍能定位和连接所有关键元素 |

“完整”既包括不漏，也包括不多。对每个具体名词问是否有原图证据，对每个数字问是计数/测量/估计，对每个新增限制问是否与可见内容相容。

## C. 三轮核查

### 第一轮：无纹理结构核查

只看版块、轮廓、关键点、文字字面及重要空隙的布局说明。暂时忽略品牌联想和微观材质；抽象图保留主导亮暗轮廓与必要色区连通性，不能把所有色场删除成一个空背景。判断是否已能区分目标构图与另一张同主题图片。

只描述了“什么东西”，却不能确定“放在哪、占多大、如何连接”，不通过。没有实际生成简图时，不能声称已经做了重绘验证。

### 第二轮：反事实消歧

检查以下变化是否仍符合提示词：主体镜像、区域高度重分配、交点挪到另一侧、文本组件移动到空角、跨区对象被裁断、共享物体复制、遮挡变孔洞、底面被删除。

有显著文字时还检查：整体上移/放大、增粗笔画、填小字腔、压缩或扩大行间空隙、改变字色层级、将标识替换为熟悉的同类图案。有显著连续背景时检查：宽窄端反转、主轴改向、边缘入口/出口改变、大色块面积变化、色带交会变成新增聚点。不是所有任务都必须含这些元素。

若某变化在原图中不成立，但文字仍允许，就补具体约束。不要无差别附加长串负面词。对于本就对称或不含相关结构的图，不制造不存在的约束。

### 第三轮：逐区覆盖与逐句去伪

从画面各区域检视提示词是否遗漏；再从提示词每句话回查图像是否支持。检查高影响边界附近的对象归属、文字归属与相对位置，最后核对小字和边缘。

受输入质量限制仍未解决的重要项，在输出外说明。不要以“模型随机”跳过可修正的漏写，也不要把每个生成偏差都武断归因于提示词。

## D. 真正的生成验证

规则存在、引用文件存在、脚本单测通过、YAML 能解析，都不等于视觉反推准确，更不等于文生图相似。

只有用户明确授权且工具能够做到**不提供任何参考图**时才运行纯文字生成测试。必须使用干净上下文，仅传最终完整提示词；若工具自动继承图片且无法排除，则该次不是纯文字测试，不伪称完成。

逐项比较实际画幅、区域、锚点、对象数量、连续性、遮挡、字形与字面几何、行间空隙、留白、标识结构、造型、连续色场形态、光色与纹理。保留失败项与限制，不用一个分数遮盖结构错误。一次生成只能说明该次结果，不能证明稳定性或锁定唯一原因。
