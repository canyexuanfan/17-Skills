# 全图视觉细节检查

这不是要求输出的分析报告。只检查实际存在的内容；不把分类清单变成向每张图片添加元素的模板。复杂结构先执行主文件和 `references/structure-and-occlusion.md` 的协议，再用本表补全信息。

## A. 全部图片

### 画布、边界与尺度

辨别显示方向、文件尺寸、目标作品尺寸、裁切、出血、内部留白、设计边框、实物相框与查看器外壳。以目标本体计算比例，不能把近似常见比例说成精确值。跨出内框的对象仍可能属于作品，不因此缩小取图范围。

区域边界、重要文字组件、主体中心与可见体量、接触点、负空间是优先锚点。尺寸不同的两张图片要归一化后比较，不能直接对比屏幕像素位置。

### 全局构图

观察最大形状、次要形状、视觉焦点、重心、对称与偏心、阅读方向、前景框景、正负空间、水平/垂直/斜向主线。把真实空间深度与平面覆盖层分别描述。

场景数量、版面分区和图层关系不互相替代。有明显分割时确认每条边界性质；没有分割时不强加分屏。区域有边界不意味着其中所有对象都在边界截断。

### 对象与关系

关键对象记录类别、可辨数量、范围/中心、体量、颜色、外形、朝向、关键局部、接触、遮挡、反射、投影、裁切与所属区域。重复出现时区分同一个连续对象、镜像/反射和不同实体。

细节不可辨时描述密度、排列、轮廓与明暗，不猜每个微物件的种类与数量。少量偏心的物件、异常轮廓和特有的连接关系不能被泛化风格词代替。

### 光影、色彩与成像

分别观察可见主光、环境光、反光、轮廓光、接触阴影；确定方向、软硬、相对强度、明暗范围、阴影形状和高光位置。没有证据时不增加耀斑、浓雾、光束或过曝天空。

色彩按区域和对象分配：主色、点缀、文字、阴影、亮部；记录面积关系、冷暖、饱和度、明度和渐变。统一暖色不等于所有区域使用相同光源或曝光。

区分真实纹理、绘画笔触、压缩痕迹、颗粒、拍摄噪点和后期效果。保留原有柔焦、景深、运动模糊、暗角和不规则性，不一律升级成极锐渲染。

## B. 人物、动物与动作

辨别全身、半身、近景或局部；记录可见身体范围和画面裁切，不补足隐藏部分。位置和关系优先于猜测身份、精确年龄或故事背景。

人物观察头部、发型、发色、可见面部特征、表情、头部倾斜、视线目标、肩线、身体倾向、肘/腕/动作末端相对位置、服装叠穿、领口、肩带、接缝、褶皱、饰品与纹理尺度。

区分粗细编织、平纹/凸纹、印刷图案/真实缝线、层叠衣物/一件衣物。衣物类型不确定时描述可见结构，不用常见穿搭补齐。看不到的裤装、鞋、配件不写。

画面左右与人物自己的左右分开。无法确定解剖左右时，用“位于画面某侧、伸向某对象的可见肢体”等方式描述。明确动作归属，不生成无来源的局部或重复肢体。接触、靠近、遮挡与影子重叠不混淆。

动物观察整体轮廓、头身比例、耳眼鼻口、花纹分布、尾部走向、可见爪部、被毛质感与环境接触。种类或品种不确定时使用保守类别，不添加物种细节。

## C. 静物、产品与功能图形

记录外轮廓、比例、材质、开孔、接缝、按键、标签、包装、高光、倒影、接触阴影、支撑平面、悬浮程度及视角。可见品牌文字按原样记录，但不能以记忆中的标准型号替换实际外观。

物件作为共享对象时，整个画面只建立对应数量的实体，动作双方描述引用同一对象。不同位置的同款物体分别定位，不能因相同外观而合并。

二维码、条码、地图和技术图不能仅靠“看起来像”保证功能或正确性。可见结构如实描述，未知载荷和数据不编造。二维码有单独功能要求时说明需要真实编码和验证，不能仅承诺文生图可用。

## D. 建筑、室内、景观与雕塑

观察墙地顶比例、门窗、构件、立柱、拱券、楼梯、家具、灯具、摆件、装饰、通道、地平线和消失方向。分别描述各场景的机位与透视；不同底图不强行合成同一真实空间。

靠边的截断物、不同深度的遮挡、框景枝条、窗内外连续性和玻璃反射都需核对。不能把窗外物体无证据地描述成室内陈设，也不能把反射当作新增物件。

雕塑检查底座、轮廓、动作、衣褶、浮雕、磨损、缺损、表面纹理与受光。微小形体不清楚就保留整体分布，不编神话故事或人物身份。建筑风格用实际形态支撑，不用地名代替描述。

## E. 摄影、绘画、插画与混合媒介

确定媒介与写实程度；混合媒介按区说明，不强制所有区域同一材质。具体观察轮廓是否描线、线宽变化、边缘锐利/晕染、色块与线条权重、阴影层数、夸张比例和透视规则。

摄影描述画面可见的机位、景深、空间压缩和畸变效果，不断言真实焦距、光圈、ISO 或机身。绘画描述笔触方向、干湿、渗化、厚薄、排线、网点、纸/画布纹；不把所有绘画都套成同一种纸纹。

三维渲染观察倒角、表面粗糙度、反光、半透明、接触阴影和几何细节。不因“3D”自动增加玻璃拟态、霓虹或金属材质。

风格名称只能作概括，需配合实际可见特征。艺术家、品牌、工作室或 IP 名称不能是唯一风格依据。

## F. 海报、卡片、书封和信息图

先找承载信息的版面结构，再读文案。标签、底板、边框、主标题、副标题、图形、正文、脚注、署名都有全局位置、父子归属和视觉层级；纯色信息区不等于可忽略的空白。

逐字保留可辨中文繁简、英文大小写、标点、空格、数字、单位、符号、换行及原有错误。文案过长不能用“其余同样”略去不同内容。小字无法确认则不猜。

字体名称不明时说明衬线、笔画粗细对比、字重、宽窄、倾斜、圆角、书写感、行距、字距和对齐。背景渐变、描边、投影、金属字、底纹和装饰分别观察，不能只说“高级排版”。

容器观察数量、范围、间距、圆角/直角、填充、边框、阴影、内部子项与被前景遮挡的部分。文本在容器内的位置不能取代容器的全局位置，也不能把容器拆散重新安排。

对图片叠字、字被前景部分遮挡、文字沿曲线或嵌在物体表面的情况，保留实际层级和透视关系；不要统一改成水平正对镜头的浮层。

文本为主视觉时，读取 `references/typography-and-spacing.md`：逐行字面、整体包络、可见空隙、字形骨架、字腔、真实字重、字色层级、与背景位置联动都需核查。字形和空隙不是只读完文案后可省略的装饰项。

## G. UI、图标、Logo、吉祥物与透明素材

UI 先确定复刻范围；顶栏、侧栏、内容区、底栏、窗口框架和查看器外壳分别判断。观察组件宽高、边距、圆角、边框、阴影、选中状态、图标数量、字体、分隔线和层叠菜单。

不按通用 UI 模板增加不存在的导航、搜索图标或顶部留白。UI 文生图提示词不是可执行前端代码，显示像素也不等于已确认的设计单位。

Logo 与图标观察几何、负空间、对称轴、连接方式、线宽、端点、角度、色块顺序、透明边距。吉祥物区分头像/局部/全身及主体类型，不能改变物种或擅自补身体。

区分 Alpha 透明、白底、半透明材质与棋盘格像素。没有透明元数据或足够证据不声称实际透明，阴影透明也不能误删。

## H. 长图、拼贴、复杂合成与劣质输入

长图按阅读路径分段查看，最后保持全局结构。拼贴确定每个区域的尺寸、边界、留缝、方向及局部内容；区域之间可能有叠放、越界、框景或连续对象，不预设互相独立。

局部遮挡、反光、模糊、压缩、缺损和水印分别记录其影响。用户未要求移除时不自动清理作品内部内容；工具/查看器外壳是否排除仍以目标范围为准。

低质量输入中优先保住区域与关系的可靠信息，不将放大后的猜测写成精确细节。完整描述可确认部分，同时诚实标出会影响复刻的缺失。

## I. 抽象背景、色场与软边形状

主导色场读取 `references/continuous-fields.md`。先观察低频亮暗形状、面积、路径、宽窄、转折、边界入口/出口和交会类型，再写局部颜色与过渡宽度，最后核查颗粒。软边不等于无形；相邻色区不等于点光源；观察分段不等于独立面板。

主要暗区和负空间与亮区同等重要。不用全图色板代替区域归属，不把颜色相同当成背景结构相同。真实光束、局部聚点、硬边或颗粒存在时准确保留，不将防止加戏变成无条件禁用。
