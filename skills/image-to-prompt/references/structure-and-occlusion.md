# 结构、连续性与局部遮挡协议

目的：避免“物件都提到了，画面仍然不是同一个布局”。这里只定义观察和表达方法，不规定任何图片应该采用的区域数量、方向、主体或配色。

## 1. 分清不同的结构层次

| 层次 | 观察的问题 | 不能混同为 |
| --- | --- | --- |
| 语义场景 | 内容属于哪些空间、环境、时刻或叙事单元？ | 版面分区总数 |
| 版面区域 | 哪些区域有独立边界、底色、留白、纹理或功能？ | 只含实体物件的区域 |
| 合成/显示层 | 哪些可见表面覆盖其他内容？ | 源设计文件的真实图层列表 |
| 对象身份 | 哪几段轮廓属于同一连续对象？ | 每一区域都新建一个对象 |
| 局部可见性 | 每个交叠位置谁在前、谁被遮住？ | 一个对象永远只在最前或最后 |

场景可以共用一个版面区域，版面区域可以包含多个层，一个对象也可以同时占据多个区域。色带、图形容器、留白和边框不因缺少实物而失去结构意义。

不要一看到多主体就判断多场景，也不要一看到一处色差就判断独立面板。用轮廓连续性、纹理变化、直线边界、透视和遮挡共同判断。可以确认视觉效果，不一定能确认制作技术。

## 2. 全图—边界—局部—全图观察

1. **全图**：看最大色块、主要边界、构图重心、长边走向、负空间和阅读顺序。暂不纠结纹理。
2. **边界带**：沿每条主要边界查看两侧；重点查看轮廓越界、文本容器边缘、嵌套框和动作连接处。
3. **局部**：放大主体关键部位、动作端点、交叠和小字；裁切预览必须保留足够上下文，不能把边界两侧拆开后猜关系。
4. **全图回查**：局部结论放回统一画布，确认没有误认归属、镜像、尺度变化或身份重复。

放大只是帮助观察现有像素，不创造新证据。没有工具时按同一顺序进行视觉复查；不要伪称执行了自动分割、OCR 或精密测量。

## 3. 区域记录与区域连接

为重要区域记录：用途、形状、全局范围、底色/透明度、是否满宽/满高、边框、裁切方式、相邻区域、子区域、被谁覆盖。区域之间可重叠或嵌套，不强制面积之和为整幅画布。

边界分成：

- **硬切边界**：两侧底图直接相接，是否有对象覆盖这条接缝要另记。
- **间隙/分隔底面**：有自己的宽度、高度、填充，不能简化成零宽分隔线。
- **渐变/混合边界**：过渡方向、带宽和纹理衔接可见，不擅自改成硬切。
- **覆盖边界**：一个表面压在另一个上面；说明下层哪里被挡、哪里仍可见。
- **嵌套边界**：内容处于框、窗、面板或局部容器内；对象是否允许越界独立判断。
- **不存在独立边界**：只是同一场景中的明暗或材质变化，不添加版面分割。

即使底图在边界处终止，也不能推定前景对象同时终止。区域被前景遮住一小部分，不意味着它本身缺了一块或被打孔。

## 4. 几何锚点与尺度

锚点选能决定构图的量，而不是把每片叶、每根毛都坐标化。

优先记录主要边界端点/走向、关键容器范围、主体轮廓范围与中心、动作节点、视线目标、消失方向、重要负空间。复杂画面通常需要比简单画面更多锚点，但没有固定数额。

所有锚点归到目标画布；子项还可增加相对父容器的位置。只给父容器内的位置而不给父容器的全局位置，仍会让整个组件漂移。只给中心而不给体量，仍会改变视觉权重。

描述可见范围，不推测遮挡后完整框。以“约”标记视觉估计；整数百分比或宽范围通常比多位小数诚实。斜边用起终点或斜向描述，不能强套水平矩形。

关键对象除了绝对位置，还要写稳定关系：位于另一对象哪侧、距离边界有多远、约为另一对象多大、是否对齐、是否超出容器。约略数字必须与自然语言方位一致。

## 5. 一个对象，多段可见性

先给连续对象一个内部标识，再按路径记录可见段。标识仅用于核查，最终提示词换成有辨识度的自然语言称谓。

对每一次越界记录以下事实：

| 字段 | 要回答的问题 |
| --- | --- |
| 起点 | 对象哪一段、位于哪个区域、从哪里开始可见？ |
| 路径 | 沿什么方向延伸，轮廓怎样弯曲或转折？ |
| 边界事件 | 穿过哪一条边界，穿越点相对画布在哪里？ |
| 前后关系 | 此处对象遮住哪一层，或被哪一层遮住？ |
| 连续性 | 是连续可见、被挡后再现，还是本来就有断开？ |
| 终点 | 落在哪个区域，接触谁，接触处是否在边界上？ |
| 支持证据 | 可见边缘、纹理延续、相同材质、连接形状或明确的遮挡线索是什么？ |

不能把“进入某区域”误写成“在该区边界处结束”。接触节点可能离边界有明显距离，需分别定位。对没有证据的不可见段，只描述被遮挡关系，不编造完整形状。

同一对象可能在不同位置交替前后，尤其是编织、环绕、穿插、反射或平面合成。使用**局部遮挡关系**，不要为整个对象建立强制的全局层序。局部判断冲突时回看图像；若是可见的不可能图形，描述其视觉矛盾，而非“修正”成正常几何。

## 6. 将叙事转换为可画关系

“互动”“连接”“共享”“穿透”都不是足够的构图说明。至少落实为：主体各自的朝向与位置、同一个共享对象、动作端点、相互遮挡、接触或间隙、视线目标、路径与边界关系。

没有接触证据就写靠近，不用动作故事补足接触。接触和视线是不同关系，不能因一方看向另一方就自动写成双向对视。抓握、搭靠、支撑、悬浮与投影相接也不是一回事。

在几何清晰时优先用位置称呼可见肢体，不强行使用解剖左右。看不到的肢体不补全；同一人的跨区部位要有明确归属，不变成无来源的悬空局部。

## 7. 文字组件的父子绑定

文字不是只有“写什么”，还包括“写在什么上”。先记录承载面形状、尺寸、颜色、透明度、边界和全局位置，再记录文字、图标与标签的局部排序、对齐、间距和层级。

组件内部若还有子标签，它与外部容器分别记录，不能因一个子项有底色就把所有文字合并成一张新卡。没有底面证据时不添加背景形状。

遇到遮挡，分别回答：遮住的是容器底色、图标、正文，还是某几个字符？容器在对象两侧是否延续？正文是否避开前景？不能为了文字清晰自动移动整组或缩小主体。

## 8. 结构完整性的三个快速判定

**轮廓判定**：只保留区域、主体轮廓、交点和文字块，文字是否已经能限定整体形态？

**多解判定**：上下关系虽然对，但左右互换、镜像、移走交点或重分配区域高度仍符合提示词吗？能成立就还缺约束。

**身份判定**：同一对象重复描述是否会让模型画出多个？不同对象是否被“同款”等话语误合并？每个接触边和遮挡边是否连接了正确对象？

优先修复高影响结构：区域与层级、对象归属、几何、文字容器；文字主导时同时锁定字面与空隙，连续背景主导时锁定主要亮暗轮廓与路径。再补材质，不用更长的氛围段落代替结构检查。
