# 字形、排版、标识与留白协议

文字主导的图片不能只读文案；字形与留白本身就是画面主体。以下是观察方法，不规定任何固定标题内容、位置、行数、字体或品牌布局。资源不可用时按主文件同名规则执行。

## 1. 观察顺序与证据

先以整幅目标观察文字组的大小、位置、层级和空隙；再查看每一行；再放大关键字形、字腔和标识路径；最后回到原尺度检查。放大不能创造原文件没有的证据。无法访问真实字体文件时不声称已识别字体名称。

文字组中分别记录：文案原文、逐行换行、整体可见边界、单行边界、行间空隙、字间间隙、对齐轴、字形、字色、边缘效果、父容器、与邻近图形/文字的关系。不要只测外框而忽略内部空隙，也不要只测单字而忽略整体位置。

## 2. 三种“大小”不能混用

| 量 | 含义 | 不能据此推断 |
| --- | --- | --- |
| 整体组框 | 所有可见文字和明确属于该组的间隙的包络 | 原始字体字号、编辑器文本框 |
| 单行字面框 | 该行实际可见笔画的外接范围 | 行盒高度、基线位置、字体 em 值 |
| 单字可见框 | 该字符笔画的可见宽高 | 每个字符都等宽、相同字重或字腔面积 |

宽占画布宽，高占画布高；像素宽高比计算时先统一单位。不能把“宽占画布的百分数”除以“高占画布的百分数”直接当成实际字形宽高比，因为画布未必是正方形。

描述位置时注明上沿、下沿、中心或基线。只读到可见字面时不伪造基线；“距顶部”若没说量的是哪一处就仍有歧义。上下沿确定后，中心和高度从同一数据派生，不再另猜一套数值。

所有手工框和阈值框都是测量近似，受抗锯齿、压缩、背景干扰和选区影响。不以工具的小数位冒充识别精度。只需足以约束布局的整数百分比或诚实近似。

## 3. 从外框到内部空隙的几何闭合

对普通水平排列、按上下顺序且上下沿单调的多行文字：

- 组高约为各行可见字面高度之和，加相邻行之间的可见空隙。
- 相邻空隙是后一行上沿减前一行下沿，不是基线间距；存在重叠时是负值，不自动纠正为零。
- 同一行总宽由可见字符宽和字符间隙共同构成；不要一边规定窄字距，一边给与之不相容的总宽。
- 单字的可见宽高比例、字体字腔大小、行总宽、字重、排版框是不同量；不能为满足一个数而任意拉伸其他量。

字距不均、光学对齐、混合文字、特殊符号、悬挂标点、连字、竖排、弯曲排版、旋转和透视字，按实际范围与路径描述，不能用普通等宽横排公式强行重建。

没有证据时不强制每行同宽、每字等宽或每行等高。居中只说明共享中心轴；左对齐不说明右沿齐；同样的字重不说明每个字符白色面积相同。

可选 `scripts/typography_probe.py` 只做已提供横排框的算术，返回实际组框、各行尺寸、间隙和外边距；不识别字体、不读字、不自动决定“紧密/宽松”，更不判断字体是否与原图一致。

## 4. 字形形态，不以类别名代替

| 检查面 | 要描述的可见特征 |
| --- | --- |
| 骨架 | 部件比例、重心、横竖关系、笔画方向、是否偏斜或端正 |
| 字重 | 主笔画相对字面高度的粗细，黑白/实空面积关系，是否各行不同 |
| 字腔/负形 | 内部空洞、部件间通道的大小、开闭、形状与拥挤程度 |
| 宽高形态 | 扁、方、窄长，是否真实压缩/扩展，单字之间的可见差异 |
| 端点与转折 | 平切、斜切、尖端、圆角、钩、弧线与收笔；仅描述实际可见者 |
| 粗细变化 | 横竖差、笔画对比、局部鼓胀、手写顿挫或几何均匀性 |
| 装饰与维度 | 平面填色、真实描边/影子/倒角/挤出/发光，不能互相推导 |

“大号标题”“粗体”“超粗”“厚重”“张力”不是可互换词。观察是大字但字腔仍开阔时，不能为了“有冲击力”把笔画填得更厚。字体只是粗体时，不能添加爆炸字、漫画字、切角字或立体效果；原图存在这些特征则如实保留。

字形细节的作用是约束外观，不是猜出专有字体。描述应足够具体但不捏造不可辨笔画，也不逐像素穷举每个字。

## 5. 字色与边缘

分别看主字面、抗锯齿边缘、投影、底形和周边色场。接近白色但带色相、偏灰、上下颜色轻变或辅助字对比度较低，都应按可见效果写，不统一提成纯白。

从合成图不能唯一恢复原始 Alpha、混合模式或设计色值。若看起来较浅、较低对比，可描述最终外观，不冒称“透明度为某值”。有取样也要标明来源区域、背景干扰与近似性。

细暗边可能是抗锯齿、锐化、压缩或真实描边；不确定时不能升级成明显描边。同理，平面粗字不等于挤出字体，柔边文字不等于光晕。

## 6. 空隙是可测结构

将文本组与画布边缘、标识、其他文本组、图形主体和背景亮暗结构之间的间隙一起看。留白可以是深色、彩色、有纹理的背景，不专指纯白底。满版出血、无外框不等于内部没有留白；不能在开头无依据写“无留白”，又在后面要求保留显著空隙。

记录重要空隙的范围、方向及相对字高大小。避免因“商业海报通常标题更大”而填满空隙，因“居中”而上移/下移，或因“紧凑”而压行。位置、字面尺寸与留白必须共同成立。

在背景有结构时，文字和背景使用同一坐标：文字覆盖哪个范围，背景边缘从哪些字后经过，哪些空隙露出亮区。不将原本独立的文本强行绑定成一个会整体移动的组件。

## 7. 标识先记录路径结构，再做类比

核对可见路径的数量或可确认范围、闭合与开口、交点、前后穿插、端点、粗细变化、对称轴、倾斜、字腔/负空间及旁边字标的比例和间距。

熟悉形状的类比只能辅助理解。先写结构，再判断类比是否会添加原本没有的轮廓、配件或实体含义。会引起这种替换时省略类比，不以品牌名称召回记忆中的标准图标。

低分辨率标识中不能确定闭合/连接关系时，描述可见曲线，不补完整闭环，也不宣称恢复了官方矢量图。

## 8. 排版反事实检查

把全部文字上下移动、放大、增重、压行、加宽行距、更换同类但不同骨架的字形、将辅助文字提为纯白、把标识改为常见相似图案，是否仍符合提示词？

只对原图中可确认且影响显著的差异补足约束。不能用几十条泛化负面词代替具体字面框、字形特征和空隙。真正没有文字的图片不运行此分支，也不添加文字。
