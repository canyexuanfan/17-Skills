# 更新记录

## 1.2.0 — 2026-09-28

### 字形、字面和留白

新增文字主视觉分支，明确字形骨架、字腔、笔画、实际字面框、行间空隙、字距、字色和负空间；区分字大与字粗、字号与字面、共轴与等宽，增加排版几何闭合检查。

### 连续色场与软边结构

新增亮暗包络、主轴、宽窄端、边缘入口/出口、过渡带和颜色路径记录。区分观察分段与独立面板、宽域交会与聚点、暗区与真实阴影、柔焦与颗粒，保留真实强效果而不机械禁用。

### 标识与约束一致性

标识先记录路径、开闭、交叉与负空间，避免由熟悉类比替换形态。新增单一描述基准、定量与定性冲突检查、作用范围检查和更细的偏差归因。

### 测量与回归

保留原图片与布局测量脚本，新增只读横排字面几何计算工具和通用算术测试。扩充相互独立的视觉验收维度；视觉用例仍为计划，不等于已执行。既有跨区、局部遮挡、文字容器、来源隔离和无工具退化流程保留。名称、安装目录和单一完整提示词输出不变。

本包仍不分发真实保留测试图、提示词答案、专名、坐标或换名同构案例；具体执行结果见 VALIDATION.md。

## 1.1.0 — 2026-09-28

### 核心流程

区分语义场景、版面区域、显示层、对象身份与局部可见性。新增边界带观察、区域与对象事实表、关键几何锚点、连续路径与局部遮挡规则。描述以整体布局和关系优先，而非先写长篇氛围。

### 文本与内容

文字、标识、标签绑定承载容器的全局位置与局部对齐。细节要求逐句回查可见证据，禁止由主题、旧提示词或生成结果补入服饰、道具和光效。移除固定篇幅配额导向，不为字数编造信息。

### 自检与修订

增加低细节轮廓核查、反事实消歧、文字归属检查和来源隔离。区分观察、编码、内部冲突、生成执行和外部设置问题，避免未经证据的单一归因。

### 工具

保留只读图片尺寸、比例和透明度测量。新增 `layout_probe.py`，仅将明确提供的框和点换算为目标内比例；不自动识别内容。增加对应算术、方向、裁切、异常、只读和静态契约测试。

### 分发与验证

补充保留测试材料隔离原则，不附真实测试图、答案或同构换名示例。视觉验收计划加入结构类正例与负例；计划不等于已执行。默认单一完整提示词输出、无需安装依赖的核心流程和名称保持不变。

## 1.0.0

初始版本：画幅、主体、构图、光影、材质、文字与边界观察；独立自然语言提示词输出；可选只读测量脚本。旧版校验结果不代替新版实测记录。
