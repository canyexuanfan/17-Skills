# 行为准则 (Code of Conduct)

本仓库采用 [Contributor Covenant](https://www.contributor-covenant.org/) v2.1 的中文版准则，旨在为所有人提供友好、开放、互相尊重的参与环境。

## 我们的承诺

作为贡献者、维护者和用户，我们承诺让每个人都能参与本项目，无论年龄、体型、可见或不可见残疾、种族、性别、性取向、经验水平、教育程度、社会与经济地位、国籍、外貌、宗教或性別认同与取向。

我们承诺以有助于建设开放、友善、多元、包容、健康社区的方式行事和互动。

## 我们的准则

有助于创造积极环境的行为包括：

- 使用友好和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 以社区的最大利益为出发点
- 对其他社区成员表示同理心

不可接受的行为包括：

- 使用性暗示的语言或图像，以及任何形式的骚扰
- 挑衅、侮辱或贬低性评论，人身或政治攻击
- 公开或私下的骚扰
- 未经明确许可，公布他人的私人信息（如住址、邮箱）
- 其他在专业场合中可被合理认为不适当的行为

## 我们的责任

维护者有责任对不可接受的行为进行澄清和纠正，并有权删除、编辑或拒绝与本准则不符的评论、提交、代码、wiki 编辑、issue 及其他贡献。

## 适用范围

本准则适用于所有项目空间（仓库、issue、PR、讨论等），以及当个人在公共场所代表项目时。

## 执行

如遭遇骚扰、不当行为或违反本准则的情况，可通过仓库 Issues 联系维护者，或发邮件至仓库所有者 GitHub 账号。所有投诉将被及时、公平地审查与处理。

维护者有义务保护举报者身份与隐私。
