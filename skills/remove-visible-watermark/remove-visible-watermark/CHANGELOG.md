# 更新记录

## 1.3.0 — 2026-10-07

### 文字分割与完整执行流程

- **框外只读上下文**：文字分割读取最多 32 像素周边进行统计，减少裁片边界补齐对掩膜的影响；写入仍受原 ROI 约束。
- **按当前字行重估尺度**：ROI 高度仅作为初始猜测，可靠字行可触发一次字高驱动的尺度重估；条件性分离亮种子的细桥，随后在字形附近有限恢复原始笔画，保留下伸笔画和原深色边缘约束。不加入品牌模板或学习型 OCR。
- **补齐弱字芯附近的短暗轮廓**：以已观察描边的对比度确定延伸门槛，只沿相邻、双侧变亮的暗轮廓做最多 3 步传播，并补一圈有暗轮廓证据的抗锯齿边；不全局扩大文字掩膜或固定样例坐标。
- **Agent 默认执行完整未知纹理修复**：显式传入 `--method exemplar --refine consensus`，一次调用完成初修与精修，不要求用户选择或串联算法。CLI 默认 `--refine none` 继续兼容旧调用；已知模板和纯色分支保留。

### 背景证据、供体约束与预算

- **原图边界背景引导**：先由原图固定边界求解低频背景，初修通过邻近原图变化范围的一致性检查后，才可作为弱匹配支撑；初修和引导图都不作为原始供体。
- **双侧可见结构支撑**：只从完全干净的原图梯度建立线条提案，遮挡跨度两端附近都必须有足够同方向边缘支撑，才能保留相应初修线条作为弱匹配延续；不将单个 Hough 提案当作真实结构证明。
- **结构引导的加权重叠融合**：使用真实原图内的 19×19 完整供体，对颜色和各供体内部梯度按空间位置、匹配误差加权融合，再固定原边界重建。平均仍可能软化木纹或错配规则纹理，不声称完整复现 PatchMatch 或其他研究算法。
- **有界供体扩展与低支持传播**：邻域内没有合格供体时，只在已预算的上下文中搜索；匹配支撑不足的块可以继承受支持邻块的供体提案，所有供体排除规则继续有效，传播块不以零误差充当独立匹配证据。
- **明确计算上限**：精修选区不超过 4 万像素，含边界扩展的上下文不超过 100 万像素，目标块中心不超过 2000 个，累计匹配位置不超过 1.28 亿；背景引导和最终重建各自最多求解 500 次。`--quality` 继续控制初始 exemplar，精修有独立预算。
- **限制可见线检查规模**：最多检查 128 个线条提案；可信边缘像素超过 5 万时跳过这项结构保护并记录警告，不将超限检查伪装成已确认的结构。
- **保留固定边界语义**：源排除和保护区域不充当供体或可信原图匹配样本，但位于写入掩膜外的原图值仍约束背景引导及最终重建。不得为规避此影响擅自扩大写入范围。

### 验证与兼容性说明

- NumPy、Pillow、OpenCV 依赖保持不变；不新增模型权重、联网处理或生成式步骤。
- 所有近似纹理修复继续标为 `needs_review`。接口回归、掩膜外零改动与线性求解收敛不等于视觉质量或真实原图精度；最终验证范围与限制以 `VALIDATION.md` 为准。

## 1.2.0 — 2026-10-07

### 修正：文字掩膜与可信支撑

- **按字高保留下伸笔画**：移除固定 `baseline + 3` 下界造成的截断，改为随字高自适应的下方余量，减轻下伸笔画及斜向字角漏选。
- **限制掩膜越过深色边缘**：形态学生长不越过明显更暗且缺少字形证据的邻近边缘，降低把桌沿等结构连入文字掩膜的风险；仍需查看选择区预览。
- **文字源排除圈**：文字掩膜额外增加 2 像素供体与可信匹配排除圈，不扩大允许写入区域；保护区与原始污染范围仍保留排除语义。
- **跨排除圈寻找可信支撑**：初始贪心填充可以使用目标补丁内部更远处的可信像素推进，不要求紧邻缺口的像素可采样；圈内被排除的原图像素仍不作为供体或可信匹配。

### 新增：显式可选的一致性细化

- **`--refine none|consensus`**：默认 `none`。`consensus` 必须与显式 `--method exemplar` 合用，可搭配 `--text-roi`、精确 `--mask`、`--source-exclude-mask` 与保护掩膜。供体、覆盖、预算或求解失败时明确报错，不静默降级或返回未细化结果。
- **完整补丁颜色与梯度投票**：从原图干净区域选取 19×19 完整供体，分别形成重叠颜色票和供体内部梯度票，以 screened Poisson 求解仅重建原写入掩膜内像素。运行时依赖仍为 NumPy、Pillow、OpenCV，不加载模型权重。
- **保留预算含义**：`--quality` 继续控制初始 exemplar 的补丁与搜索预算；consensus 参数固定，不把更高 quality 当作细化效果保证。
- **Agent 直接选择一次运行流程**：连续渐变、低对比细纹且注重接缝时，可首次调用就启用 consensus；强规则纹理和锐利结构要谨慎复核，不要求用户手工串联算法。

### 能力边界与资料

- 重叠投票可能使细纹变软；有输出仍标 `needs_review`，不承诺无损恢复或找回真实被遮背景。
- 被源排除但留在写入掩膜外的像素仍是 Poisson 固定边界值，可能影响相邻修补颜色；它们不因此作为供体或匹配样本。
- 在算法文档中补充原始论文链接，明确为自写、固定预算的工程简化版；未复制开源参考实现，不声称完整复现论文。
- 保留 README 原许可段及全部历史变更记录；实际验证范围与限制见 `VALIDATION.md`。

## 1.1.0 — 2026-10-07

### 新增：指定文字区域的掩膜细化与同图纹理修复

- **文字范围细化（`--text-roi`）**：Agent 或用户先定位水印，算法在限定区域内提取浅色笔画、暗描边和边缘，不依赖固定品牌字形模板。检测范围不会自动变成整块矩形擦除范围；无法得到可靠掩膜时明确报错，提示缩紧区域或使用精确 `--mask`。
- **同图补丁修复（`exemplar`）**：从原图的完整区域搜索相似补丁，按可信邻域匹配，在掩膜内恢复可借用的局部纹理。结果属于近似重建，标 `needs_review`，不声称找回真实被遮内容。
- **计算预算三档（`--quality fast|balanced|high`）**：调整 exemplar 补丁与搜索范围，默认 `balanced`；较高档位增加计算量，不保证结果总是更准确。
- **未知水印自动分流升级**：已有纯色背景与已知模板路径保留。对已确定修补范围且无校准模板的水印，`auto` 优先 exemplar；源补丁或资源预算不足时，只尝试一次 NS 回退并记录原因。显式指定 exemplar 时失败直接报错。
- **供体与保护掩膜分离**：先保存完整水印排除范围，再从允许修补范围扣除 `--protect-mask`；内部 `source_exclusion` 防止受保护的残留字样被作为可信邻域或纹理供体复制。
- **显式供体排除（`--source-exclude-mask PATH`）**：将用户指定区域排除出 exemplar 的供体和可信匹配区域，不增加写入范围，不等同于 `--protect-mask`。可与 `--text-roi`、`--mask`、`--roi` 之一合用，但必须显式指定 `--method exemplar`；拒绝与其他方法合用及批量共享，供体不足直接报错。
- **有依据的单次修复重试**：首轮对比若发现借入邻近异材质、正常文字或桌沿，可生成供体排除掩膜，保留原图及原写入选择范围，从 auto 改为 exemplar 后另存重试一次。仍标 `needs_review`，不将提高质量档位当作必然改善，也不宣称语义自动识别材质。
- **输出升级为六件套**：处理图、实际改动 `.mask.png`、允许修补 `.selection.png`、局部 `.comparison.png`、范围叠加 `.selection-preview.png` 和 `.report.json`。`--no-preview` 可省略两张预览图。
- **保留原始分辨率**：按原始像素处理局部区域，不通过预先缩小原图降低修复成本；预览缩放不影响输出处理图。运行时依赖仍为 NumPy、Pillow、OpenCV，未新增模型或第三方运行库。

### 使用边界与兼容性

- 新文字入口针对指定区域中的浅色文字及暗轮廓，不承诺全图纯盲识别或处理任意水印；深色文字、彩色 Logo 和复杂遮挡继续使用精确掩膜。
- `--corner-text` 仅为保守的实验性角落候选入口，不替代 Agent 定位或精确掩膜；不确定时跳过。
- 保留 `--mask`、`--roi`、`--protect-mask`、手动 Telea / NS、已知模板批量处理与像素级校验。`--text-roi`、`--mask`、`--roi` 互斥；各张位置不同的未知水印需逐张调用。
- 掩膜外像素不变、透明通道不变和范围校验通过，仍不代表水印已经去净或背景无痕恢复；需要结合掩膜预览与处理前后对比复核。
- 保留原作者、MIT 许可声明及第三方依赖致谢，新增修复代码为原创实现。

## 1.0.0 — 2026-10-07

### 首发：纯算法可见水印去除

- **模板检测与反算（profile auto）**：内置 WorkBuddy 角标「AI生成 / WORKBUDDY」半透明水印模板，按字形、灰度、梯度和反算一致性检测，允许有限位置校正与等比例缩放；按已知 alpha 与前景色反算还原背景。
- **纯色背景修复（fill）**：水印周围及字间空隙提供一致纯色证据时，估计背景色仅填修补掩膜。
- **局部插值（telea / ns）**：手动掩膜或 `--roi` 矩形区域，比较两个传统插值候选，结果标 `needs_review`。
- **自动分流与诚实跳过**：`--method auto` 按证据强度分流；无匹配直接输出未修改副本并标 `skipped_no_match`，不降低阈值强行擦除。
- **批量处理**：`--input-dir` 批量同款水印，保留相对子目录，`summary.json` 汇总。
- **像素级校验**：报告含 `input_unchanged` / `outside_mask_changed_pixels` / `alpha_changed_pixels`；输出四件套（处理图/掩膜/对比图/JSON 报告）。
- **隔离环境自举**：`bootstrap.py` 探测依赖，缺失时创建独立缓存环境按 `requirements.txt` 锁定版本安装，图像处理不联网。

### 设计边界（写入文档，不做超出实测的承诺）

- 只支持静态 8 位图（≤4000 万像素），拒绝动图、多页、非常规像素模式。
- 不处理隐形水印（频域修改不属于可见水印范畴）。
- 无干净原图时不宣称"原图恢复精度"——反算/插值的假设全部写入报告。
