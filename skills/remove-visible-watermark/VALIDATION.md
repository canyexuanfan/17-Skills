## 已修正的选区与实际样图

背景统计改为框外 32 像素只读上下文，可靠字高只再估核一次，先分离可能把场景亮边粘到文字的一像素细桥。右细钩的暗描边虽然仍有负残差，却超出普通邻域；现在依当前字形的双侧暗谷对比度，沿相邻强暗轮廓最多延伸 3 步并补有限抗锯齿边，没有固化样图坐标或整框擦除。

四个固定框均覆盖检查的 11 个右侧描边点及 4 个下伸点，正常桌沿两点与一处正常暗木纹保持未选。窄/宽框得到相同的 10,930 像素选择区；外框/独立使用框得到相同的 10,929 像素选择区。不同组仍有细微差别，不能声称任意框选均完全相同；这些人工检查点也不是完整分割真值。

本次成品在原始 1536×2048 RGBA 输入上运行 `--text-roi 1252,1954,1512,2024 --method exemplar --refine consensus`，**不提供人工取样排除掩膜**。选择区 10,930 像素、实际变化 10,916 像素；原输入不变、选区外改动 0、alpha 改动 0。查看完整图及同位置最近邻放大后，已定位的字尾和右细钩残影消除，没有观察到把椅背暗块复制进桌面的现象；局部细木纹仍有柔化，隐藏背景没有真实干净图可验证。

## 独立使用与受控重放

独立使用者仅从 Skill 和原图开始，自选 `1248,1955,1516,2029`，首轮发现末字右侧暗钩漏选，并通过一次手工精确掩膜修正完成。这一问题随后写入检测算法。

最终以同一首轮框在最终源码上受控重放，不使用该手工掩膜，也不加人工来源排除；选择区 10,929 像素。原尺寸及同位置残片检查记录保存在机器验证中。它证明已报告问题在相同调用条件下得到修正，不能称作第二次全新盲测或未知图片的普遍自动成功率。

## 有真值原尺寸对照与保留的代价

固定四例使用同一精确掩膜、同一 balanced 参数。两张真实素材是原图直接裁出的 340×112 桌沿与 206×56 木纹，背景没有缩放；另外两例为斜边细纹合成图及严格单一来源区。叠加参数和 clean 只用于评测，没有作为修复输入。

数值为 0–255 RGB 量纲的区域误差，越低越接近已知真值。表中比较的是 v1.2 consensus 与最终 v1.3 consensus。

| 场景 | 掩膜 RGB MAE | 梯度 MAE | 内边界 MAE |
| --- | ---: | ---: | ---: |
| 原生桌沿 | 5.140000 → 5.595789 | 2.913679 → 2.975432 | 2.257384 → 2.371308 |
| 原生木纹 | 1.760234 → 1.833333 | 1.189887 → 1.209123 | 1.205607 → 1.386293 |
| 合成斜边细纹 | 0.769038 → 0.768759 | 0.639927 → 0.708088 | 0.501475 → 0.529499 |
| 单一干净来源区 | 0.230769 → 0.246795 | 0.337589 → 0.348936 | 0.212963 → 0.259259 |

最终四例相对于基础 exemplar 初修的 MAE 均降低，但相对于 v1.2 consensus，三例 MAE 增加，一例近乎持平；四例梯度与边界误差均有增加。不能用“新版本”或 24 项通过声称所有画质指标都改善。木纹高频 RMS / 真值从约 0.518 提高至 0.626，仍偏软；合成细纹的该比率从约 0.974 降至 0.938。纹理能量不等于纹理准确性。

开发中曾采用硬供体选择以减少平均软化，结果在原生桌沿上产生明显断亮边；该候选已撤回。诊断发现，局部原图统计缺少被遮住的细亮线，会把正确初修错误替换成调和背景。最终依据跨度两端可见、方向一致的干净边缘保护初修延续，并恢复加权重叠供体均值。结构保护只使用完整干净梯度，最多检查 128 个线提案；超过 50,000 可信边像素时明确放弃此保护并报告。均值融合有助衔接，仍可能软化纹理。

## 分发与可复核内容

运行时依赖不变。所有供体来自真实原图中的完整块；初修、调和引导和可见结构保护只用于匹配。源排除区内、但保留在写入区外的原像素仍会约束 Poisson 固定边界，此含义没有变成“排除后完全不影响颜色”。

## 固定的有真值小样例

同一精确文字掩膜、同一 balanced 初修；比较初始 exemplar 与固定 19×19 consensus。指标按修复区域计算，RGB MAE 为 0–255 量纲；梯度定义见机器记录。下列数据来自最终交付源码。

| 场景 | RGB MAE：初修 → 精修 | 局部梯度 MAE：初修 → 精修 |
| --- | ---: | ---: |
| 平滑渐变 | 0.014547 → 0.014469 | 0.012765 → 0.011372 |
| 方向纹理 | 0.563835 → 0.417673 | 0.246913 → 0.194230 |
| 斜直边 | 0.783349 → 0.497060 | 0.283954 → 0.183856 |
| 缩放后的真实木纹裁图 | 3.047469 → 1.863345 | 0.940260 → 0.581960 |

这是三张 420×280 合成图片与一张 512×256 木纹例。木纹来自原图 605×50 裁区，**先缩放再叠加合成水印**；它不是原尺寸真实照片的直接恢复试验，不可外推普遍胜率。四例的掩膜外 RGB 改动均为零，原输入不变；alpha 由调用层原样接回，不能当作内部 RGB 算法原生支持 RGBA 的证明。

不能只汇报平均改善：渐变的平均误差变化非常小，掩膜内侧边界 MAE 从 0.010915 上升到 0.013154；斜直边最大通道误差 P95 从 2 上升到 3。木纹的梯度能量比从约 1.173 降到 0.886，与目视的细纹软化一致。精修适合缓解部分接缝，不保证每处细节都更准确。

## 用户样图：修正的具体细节

- 原图 `image(2).png` 为 1536×2048 RGBA；始终在原尺寸处理，展示裁图只用于放大检查。
- v1.1.0 漏选“成”的下伸描边。该残片又进入干净供体，在另一个位置复制出暗点；已找到 5×3 区块逐像素相同加有界颜色偏移的证据。本版扩大字行的合理下伸余量，并给文字取样排除增加 2 像素圈，圈不增加写入区。
- 原图桌沿的 `(1489,1962)`、`(1490,1962)` 被旧掩膜误选并补亮。现在限制新增形态学像素跨越明显深色物体边缘，这两个点保留原像素。
- 使用原图与已检查的供体排除，运行 `--text-roi 1258,1956,1510,2023 --method exemplar --quality balanced --refine consensus`。从完整供体内部独立投票梯度，再在固定原边界内求解，减少硬贴补丁的接缝。
- 最终选择区 11,033 像素，实际改动 11,016 像素（约 0.3502%）；尺寸与 alpha 保持，选区外改动为零，原文件 SHA-256 不变。
- 已核对下伸暗点、被复制暗点和桌沿凸起的同位置放大图；这些可定位缺陷消除，接缝减轻。木纹仍可能变软，背景本来的细节没有干净真值可验证。最终保持 `needs_review` 和 `true_original_accuracy=null`。

## 独立使用暴露的限制

另一个独立使用过程仅拿到 Skill 和原图。它使用稍宽的 `1252,1954,1512,2024` 框时仍误选部分桌沿与椅背，修复借入了异材质。依据原图剪除 853 个明显误选像素后，选择区为 11,205 像素；再严格排除非桌面来源，consensus 报 `incomplete color-vote coverage`，未输出成品。

相同掩膜与来源限制下，显式基础 exemplar 可以输出，但仍有可见块状与色调接缝，没有当作本次精修成品。开发时另试一次 11 像素块仍缺必需梯度支持；该自适应试验已撤回，不在交付实现中。

因此，本版没有解决任意区域的自动语义选择，也不能保证在严格供体限制下都能完成精修。Skill 已明确要求查看选择区、按证据修正误选，并如实交付失败信息；不扩大写区或放宽用户排除范围来凑出结果。

## 已知限制与行为说明

- `bootstrap.py` 的探针只验证依赖可导入、不校验版本：若机器上已有可导入但不匹配版本的 OpenCV，会直接使用现有解释器而不装锁定版本。新机器（无依赖）会走 `--install` 得到与本次测试完全一致的环境。
- 模板反算要求背景不透明且合成参数一致；大块不透明遮挡只能近似插值并标 `needs_review`，超出局部修复限额会明确报错。
- 无干净原图时，视觉改善不等于原图恢复——此结论已写入 SKILL.md 与报告语义，不宣称恢复精度。
- 未在 macOS / Linux 实测；未测试 CMYK / 16 位 / 动图（按设计应拒绝）。
- 自动模式匹配阈值保守，宁跳过不误擦；跳过不代表图上无水印。
